# CUMCM 高质量论文模式（winning_patterns）

> 这是写作与复核启发，不是官方评分细则，也不能预测奖项。样本清单记录了 91 份公开论文来源，其中 59 份满足当前文本提取条件；这里引用的分位数只描述这 59 份可提取子集。每年比赛以同目录 `current_rules.md` 链接的官方文件为准。

## 1. 摘要是一张结果地图

高信息密度摘要通常同时回答五件事：

1. 解决什么问题，关键约束是什么；
2. 每个子问题采用什么模型或算法；
3. 得到哪些可核验的数值结果；
4. 怎样验证误差、敏感性或稳健性；
5. 模型的适用边界与可推广场景是什么。

它们可以写成三至五段，不必机械凑段。归档的 59 份可提取样本中，摘要中文字符数 p25 / p50 / p75 为 748 / 992 / 1146；PDF 解析会带来误差，因此这些值只用于发现“过短、无结果”或“过长、失去摘要功能”等异常。

摘要中的每个数值都应能在正文或结果文件中追溯。没有真实计算结果时，宁可标记待补，也不要使用占位数字。

团队摘要采用固定骨架并控制铺满第一页：背景 1 段（3—4 行）+ 每问 1 段（段首"针对问题 X："，6—8 行，先方法后结果、有验证写验证）+ 关键词 1 行；总段数 = 背景 1 段 + 问题 N 段 + 关键词 1 行，单倍行距下刚好填满 A4 第一页，不足时扩写问题段的结果与验证细节。

## 2. 目录展示推理链

一个稳妥的主线是：

```text
摘要 → 问题重述 → 问题分析 → 假设与符号
     → 分问题建模、求解与解释 → 验证/稳健性
     → 模型评价与推广 → 参考文献 → 附录
```

章节数量本身不产生质量。真正要检查的是每一问是否完成“题意 → 数学对象 → 求解 → 结果 → 现实解释”的闭环，以及后续问题是否正确使用上游结果。

电子论文的格式要求会变化。当前基线要求摘要作为第一页、不放目录、不暴露身份，正文不超过 30 页；提交前必须重新核对 `current_rules.md` 与当年官方通知。

## 3. 图表服务于证据，而不是密度

一张图或表至少应承担一种职责：

- 解释数据与异常处理；
- 展示算法、依赖或决策流程；
- 报告核心结果与对比基线；
- 说明误差、敏感性或失稳边界。

标题、坐标、单位、图例和数据来源应自洽，正文先说明“为什么看它”，再解释“它证明了什么”。59 份样本的图数 p25 / p50 / p75 为 5 / 8 / 20，表数为 4 / 6 / 9；题型差异很大，不应把这些分位数变成配额。

## 4. 模型名称必须对应真实设计

名称的作用是让读者快速识别结构，而不是用“改进”“混合”制造创新感。建议使用：

```text
<关键机制或约束> + <核心模型> + <求解/校正方法>
```

例如，只有在确实引入动态权重时才写“动态权重”；只有在两个模型的输入、损失或决策真正耦合时才写“混合”。正文应明确说明与标准方法相比改了什么、为何需要、代价是什么。

## 5. 子问题之间保留可追踪的复用链

当题目逻辑存在依赖时，后续问题要显式引用上游产物：参数估计、最优方案、预测值、约束边界或评价权重。每次复用至少写清：

- 来源问题与结果版本；
- 进入本问的变量或文件；
- 单位、索引和转换；
- 上游误差怎样传播到本问。

若各问本来相互独立，不应为了“看起来完整”强行制造依赖。

## 6. 假设要有依据，也要能回检

每条假设应附一种可核验依据：题目条件、附件数据观察、物理或业务规律、参考文献。模型和结果完成后再回检：假设是否被数据推翻、是否限制结论、放宽后结果是否显著变化。

符号表与假设表必须和正文同步。符号首次出现时说明含义与单位，同一符号不要跨子问题换义。

## 7. 验证设计与模型风险相匹配

不要默认所有问题都需要同一种灵敏度分析。按模型风险选择手段：

- 预测问题：留出验证、交叉验证、基线比较、误差分层；
- 优化问题：可行性检查、上下界、替代求解器或小规模精确解；
- 评价问题：权重扰动、排序稳定性、一致性检查；
- 仿真问题：随机种子、多次重复、置信区间、极端场景；
- 关键参数耦合明显时：再使用多变量联合扰动或全局敏感性方法。

结论应量化“在哪个范围内保持稳定、越过什么边界会失效”，并解释该范围为什么符合实际。

## 8. 模型评价要写边界与代价

有效的局限性说明包含四部分：观察到的限制、受影响的结论、可替代的方法、改进所需的数据或计算代价。不要虚构“预计提升 3%”之类未经实验支持的幅度。

推广同样要写适配步骤：哪些参数可复用，哪些数据必须重采，哪些约束会改变。只写“可推广到其他领域”不构成证据。

## 9. 参考文献、代码与 AI 披露形成证据链

参考文献没有通用的最低条数。数量应由实际使用决定：模型选择、参数来源、假设依据和对比方法都要在正文对应位置引用，列表与正文一一匹配，并采用当年要求的格式。

引用在结构上至少覆盖三类：经典开山（如 Clarke-Wright、Dantzig）、近年（近 3 年）综述与期刊、本场景的应用/工程论文；只堆经典 VRP 文献会让方法论显得停留在早期，缺领域前沿支撑。

附录与支撑材料只保留复现所需的代码、数据说明和关键中间结果；删除调试日志、凭据、个人与学校信息。代码开头注明对应正文小节、入口命令、随机种子和主要依赖。

使用 AI 工具时，按 `current_rules.md` 的当年要求进行文内标注、参考文献登记和使用详情记录；不要等终稿时凭记忆补写。

## 10. 怎样使用样本观察

- `empirical.json`：59 份可提取样本的结构化观察值；91 是来源总数。
- `empirical_notes.md`：同一批观察的人读说明与提取限制。
- `distilled_structures.md`：从观察值提炼的结构提示。
- `anti_patterns.md`：终稿检查项，不是扣分公式。
- `paper_skeleton.md`：可替换占位符的写作骨架。

先用样本分布发现异常，再回到题意、真实结果和官方规则做判断。分位数是参照物，不是把不同题目压成同一篇论文的模板。

## 11. 语言与排版规范

维护者补充的写作呈现约定，与 `anti_patterns.md` §I 的检查项一一对应：

- **英文缩写首次给出完整形式**：首次出现写"中文全称（English Full Name, ABBR）"，如"季节自回归积分滑动平均（Seasonal Autoregressive Integrated Moving Average, SARIMA）"，后文方可直接使用缩写；
- **正文引用定位**：引用只出现在问题分析与方法首次介绍处；摘要、结果、结论与展望不出现正文引用，参考文献列表与正文一一对应；
- **标点空格一致**：中文标点后不留多余空格，英文单词之间按英文规则保留空格，全文标点后的空格保持一致；
- **图表宽度**：单张图宽度约为版心 70%，多图并排时各图宽度之和也约为 70%，按比例缩放、不拉伸不变形，字号与线宽全文统一。

## 12. 五十篇获奖论文批量学习结论（2021—2025，五批 × 10 篇）

> 来源：`论文语料/batch1`–`batch5` 的 50 篇国赛获奖论文 OCR 文本（A/B/C/D/E 全题型，含同题不同队对比）。以下是从中归纳的高频写法，作为写作与复核的补充启发。

### 12.1 五条高频铁律（50/50 一致）

1. **前置四件套标配**：问题重述 → 问题分析（逐问 2.1/2.2…）→ 模型假设（有序编号 + 依据）→ 符号说明（三列表格：符号/含义/单位）。约 90% 论文四件套齐全；个别论文把"问题分析"并入各分题内部或把"假设/符号"合并为一章，但核心要素不缺失。
2. **分题建模绝对主流**：每个子问题独立一级标题「问题 X 模型建立及求解」。两种版式并存：① 每问独立一级章（约 40%）；② 在「模型的建立与求解」总章下设 5.1/5.2 分节（约 60%）。关键是一问一模型、正文按题号组织、后续问题显式"沿用/修改"前问模型。
3. **分题内三段式固定**：「模型建立 → 求解算法 → 结果与分析」，编号常达四级（5.1.2.2），或用 Step1/2/3、情形(1)(2)(3) 组织。求解后必跟"结果分析"，多数再加检验/灵敏度。
4. **摘要逐问式带数值**：「针对问题一…（方法 + 具体数字结果）…针对问题二…」，关键词放末尾。这是全部 50 篇最一致的"得分摘要"写法——评委不看正文即可抓分。
5. **多方法交叉验证成加分标配**：直接计算 vs 牛顿迭代、贪心 vs 模拟退火、多元回归 vs 随机森林、解析解 vs 数值解（拉普拉斯/复数解 vs 龙格库塔/ode45）、M-K vs Fisher、LDA vs 多分类器。并配灵敏度/稳健性分析，形成"建模—求解—检验"闭环。

### 12.2 分题型方法主线（按题型对应）

- **机理仿真类（A 题）**：先推导核心机理方程（运动/波动/干涉/受力），再时空离散化 + 数值求解；常见亮点为"解析解 + 数值解双路径交叉验证""先证明几何结论再求解"（定理-证明推进、力电比拟）。
- **优化调度类（B 题及部分 C 题）**：先定义决策变量/目标/约束，小规模用精确求解器（整数规划、线性规划、动态规划、贪心/遍历），大规模用元启发式（遗传/差分进化/粒子群/模拟退火）；常见亮点为"多算法结果对比 + 收敛性分析""双目标/多目标规划 + CVaR 风险控制"。
- **数据统计类（C/E 题）**：数据预处理独立成章或下沉为模型章首节；按"描述性统计 → 关联/回归 → 预测/分类 → 综合决策"递进；常见亮点为"多方案对比选优"（LDA vs 多分类器、线性 vs 非线性降维、六模型交叉验证）、假设检验（正态性/方差分析/K-S）、ICC/AIC 模型比较。
- **综合规划评价类（D/F 题）**：先建指标体系 + 综合评价（熵权/TOPSIS/AHP），再结合规划/仿真/情景分析；常见亮点为"情景对比 + 灵敏度 + 可行性落地"。

### 12.3 加分细节（拉开获奖差距）

- 前置章节顺序可微调（假设在前或符号在前），但内容完整；
- 每问结束都写"结果分析 + 原因分析"，不只给数字还要解释为什么；
- 高维解空间普遍降维：固定部分变量、分区对称假设、主要目标法、化简为可遍历；
- 结果落地可交付：保存 resultX.xlsx、提供交互网页/支撑材料；
- 题目命名用「基于 XX 的…」句式直点方法主线；
- 模型假设逐条附"说明/理由"，符号表含单位与注释。

### 12.4 与现有骨架的对应

本批观察与 `paper_skeleton.md` 的分题型子标题体系、前置四件套、分立式一级标题骨架一致，无需推翻重写；上述"多方法交叉验证""解析+数值双路径""同题多方案对比"是写作阶段可主动强化的加分项。
