# 阶段 4 · 稳健性总检验（BZD 双审精制流）

完整规则见主 Skill `cumcm-bzd-2026`（references/stage_06、template_library/chapter05_model_solving.md 的灵敏度/稳健性/误差三节），本文件为阶段入口指令。

## 本阶段任务

1. **全文验证矩阵**：每个影响结论的主张 → 独立校验路由（正向重构/守恒与状态平衡/对称与单位不变性/留出实体或时间验证/残差与显著性/校准与区间覆盖/噪声-参数-预处理-分组灵敏度/solver gap 与多种子/导出结果目标重算/高保真重评粗模型最优）。每主张至少一项匹配其风险的校验，不凑数量。
2. **稳健性分析**：改变输入数据/样本规模/异常值处理/权重/初值/假设 → 主要趋势/排序/最优方案是否不变；给出量化稳定区间，禁止"结果较稳定"。
3. **误差传播链**：前问误差（测量/缺失处理/模型简化/参数估计/数值与随机算法）如何进入后问输入并最终影响结论；给出平均/最大误差或置信区间，禁止"误差较小"。
4. **失败边界**：列出使解释或最优方案失效的条件组合；写明未验证风险及其影响。
5. **断链清零复核**：阶段 2 登记的断链是否闭环；代理模型最优是否回原系统重评；不可行解是否排查。

## 产物

- `ROBUST_REPORT.md`：验证矩阵（主张/校验路由/证据/状态）+ 稳健区间 + 误差传播链 + 失败边界
- `state/decision_log.json` 更新（stages.4）

## 质量门

- 验证矩阵每行有证据路径；稳定区间量化；失败边界明确；无 P0/P1 残留。
