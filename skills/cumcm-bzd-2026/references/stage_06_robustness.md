# Stage 6 · 检验与稳健性

## 目标

回答一个问题：**如果条件变了，结论还成立吗？**

本阶段不是给论文加一个"灵敏度分析"的章节充门面，而是量化结论的适用边界。

## 时长

2–3 小时

## 输入

- 各子问的模型、代码与结果（Stage 5）
- 假设表（Stage 4）
- 数据资产清单

## 执行步骤

### 步骤 1 · 选择检验方式

按模型风险匹配，不必全做：

| 风险类型 | 检验方式 |
|---|---|
| 估计参数不确定 | 灵敏度分析、情景分析 |
| 数据扰动 | 稳健性检验、Bootstrap |
| 过拟合 | 交叉验证、独立测试集 |
| 模型设定错误 | 残差诊断、拟合优度 |
| 求解质量 | 多算法对比、下界/精确解参照 |

是否单列章节取决于题型与当届要求。

### 步骤 2 · 模型检验

至少覆盖：

- **残差分析**：残差是否随机、有无结构
- **拟合优度**：报告具体指标与数值
- **交叉验证**：折数、指标均值与标准差
- **对比实验**：与简单基线或替代模型的同指标对比

**优化题需补最优性证据**：若求解主线是局部贪心或启发式，至少补其一——

- (a) 一层全局优化（遗传算法、ALNS 等）与启发解作同指标对比
- (b) 一个可算下界（MST 权重、LP 松弛）或小规模精确解，报告 `(启发解 − 下界) / 下界` 的 gap

两者都做不到时，在 Stage 7 如实降级为"启发式可行解、未证最优"，**禁用"接近最优"等无证据措辞**。

### 步骤 3 · 灵敏度与稳健性

**禁止仅做单因素（OAT）分析。**

单因素分析在参数存在交互时会低估不确定性。判断标准：如果两个参数共同影响同一个中间量，它们就是耦合的，必须做联合扰动。

| 方法 | 适用 |
|---|---|
| 联合扰动网格 | 参数少（≤4）且耦合明确 |
| 拉丁超立方（LHS） | 参数较多，需覆盖分布 |
| Sobol 指数 | 需量化各参数贡献占比 |
| 情景组合 | 参数代表离散的业务/物理情景 |

若单因素分析确实足够，必须说明参数独立性依据。

**扰动幅度必须切合实际**：用数据波动、测量误差、业务边界或文献给出范围，并解释为何覆盖主要不确定性。把价格从 100 元扰动到 100 万元不提供任何信息。

**必须报告稳健区间**，而不是结论式断言：

| 不合格 | 合格 |
|---|---|
| 灵敏度分析显示模型稳健 | 在 α ∈ [0.3, 0.5]、β ∈ [0.2, 0.4] 的联合扰动下，目标函数变化 < 5%，最优解排序保持不变 |

**蒙特卡洛必须声明种子**：固定并记录种子、软件版本、采样设置与模拟次数。需要多种子评估时报告分布，而不是只固定为一个数字。

### 步骤 4 · 失败边界

明确写出：什么条件下结论不成立。

- 参数超出什么范围结果翻转
- 假设失效时影响哪一环
- 数据分布变化时模型是否仍适用

### 步骤 5 · 结果合理性核验

逐项检查，并记录检查过程：

- 数量级是否合理
- 单位是否闭合
- 趋势方向是否符合领域常识
- 边界值是否退化到已知情形
- 异常结果是否有解释

**不能把 AI 的主观判断作为结果正确性的唯一证明。** 核验依据必须是可复算的。

### 步骤 6 · 结果一致性检查

| 核对项 | 内容 |
|---|---|
| 程序输出 ↔ 正文 | 正文数字是否来自真实输出 |
| 图表 ↔ 表格 | 同组数据在图表中是否一致 |
| 摘要 ↔ 正文 | 摘要数值是否与正文一致 |
| 结论 ↔ 数据 | 结论是否被数据支撑 |

## 产物

`decision_log.json` 的 `stages.6`：

```
params_varied_jointly  联合扰动的参数与范围
method                 检验方法
deltas                 各参数变动对结果的影响
robust_intervals       稳健区间（必须是数值区间）
stability_verdict      稳定性结论
failure_warning        失败边界
L2_backtrack           跨阶段回检发现
figures                检验图表
```

## 5 维评分

| 维度 | 判据 |
|---|---|
| `1_multivariate_perturbation` | 是否做了联合扰动（非仅 OAT） |
| `2_perturbation_realism` | 扰动幅度是否有数据/文献/业务依据 |
| `3_robust_interval_quantitative` | 是否报告数值区间而非定性断言 |
| `4_failure_boundary` | 是否写明结论失效的条件 |
| `5_cross_check` | 是否做了输出-正文-图表-摘要的一致性核对 |

## 检查清单

- [ ] 检验方式与模型风险匹配
- [ ] 残差/拟合/交叉验证至少覆盖其一
- [ ] 优化题补了最优性证据或已明确降级
- [ ] **做了联合扰动**，不是只变一个参数
- [ ] 扰动幅度有依据，不是随手 ±10%
- [ ] 稳健区间是数值，不是"模型稳健"
- [ ] 蒙特卡洛声明了种子与次数
- [ ] 写明了失败边界
- [ ] 做过数量级、单位、趋势检查
- [ ] 核对过输出、正文、图表、摘要的一致性

## 常见失败

| 失败 | 表现 |
|---|---|
| 仅 OAT | 只单独变一个参数，忽略交互 |
| 幅度失真 | 扰动范围与实际波动无关 |
| 定性断言 | "灵敏度分析显示模型稳健"，无数值 |
| 无失败边界 | 只说好的一面，不说什么时候会失效 |
| 种子缺失 | 蒙特卡洛结果不可复现 |

## 与 Stage 7 的衔接

本阶段产出的稳健区间与失败边界，是 Stage 7 "模型缺点"的直接依据。**缺点是检验出来的，不是编出来的。**

### 灵敏度分析章节的位置

> 来源：PDF L1521

十五、灵敏度分析章节的位置
1. 全文使用同一模型或同类模型
可以单独设置“模型检验与灵敏度分析”一章，统一比较各问题参数对输出的影响。
2. 各问题模型类型差异较大
评价、预测和优化模型的检验方式明显不同，应分别放在各模型板块内部。
3. 只有主要模型需要分析
只针对决定最终结论、参数依赖较强或参数来源不确定的主要模型进行灵敏度分析。
其他模型可使用误差分析、交叉验证、稳定性检验或对比实验。
核心原则：灵敏度分析的位置由模型之间的同质性决定，不能为了形式完整要求每个模型机械地重
复相同分析。
