## 明文规定的部分

国赛只对**页边距、页码编号、目录、文章篇幅**四项作详细规定：

| 项 | 规定 |
|---|---|
| 纸张 | 白色 A4，单双面均可 |
| 页边距 | 上下左右各 ≥ 2.5 cm，左侧装订 |
| 第 1 页 | 承诺书（按当届模板） |
| 第 2 页 | 编号专用页 |
| 第 3 页 | 摘要专用页，含标题与关键词，**不超一页**，无需英文翻译 |
| 页码 | 从摘要页开始，页脚中部，阿拉伯数字从"1"连续编号 |
| 第 4 页起 | 正文，**不要目录**，尽量 ≤ 30 页 |
| 正文之后 | 附录（页数不限），必须打印并与正文装订在一起 |
| 匿名 | 摘要页、正文、附录任何位置不得有参赛者身份、学校、赛区信息 |
| 引用 | 引用他人或公开资料（含网络资料）必须列出参考文献，并在正文引用处标注 |
| 字号字体行距颜色 | **不做统一要求**，各赛区可另行规定 |

## 未作规定但广泛采用的惯例

以下不是国赛规定，是长期流传形成的通行做法：

| 项 | 通行做法 |
|---|---|
| 摘要篇幅 | 约 800–1000 字 |
| 关键词 | 4–6 个 |
| 章节体系 | 问题重述 → 问题分析 → 模型假设 → 符号说明 → 数据与预处理 → 各问建模求解 → 模型评价与推广 → 参考文献 → 附录 |
| 三线表 | 顶线、表头下线、底线，无竖线 |
| 公式编号 | 章节级，如 (5.1)、(5.2) |
| 图表题注 | 图题在下方，表题在上方，按章连续编号 |

## AI 使用披露（2026 年）

| 情形 | 要求 |
|---|---|
| 未使用 AI | 正文中提供《AI 工具使用声明》，写明"未使用任何 AI 工具" |
| 使用 AI | 正文提供声明 + 支撑材料《AI 工具使用详情》 |

详情材料需按用途类别逐条说明：AI 提供了什么、主要用于什么、**参赛队如何人工核验**。

分类与核验要求见 `ai_usage_governance.md`。

## 易错点

| 易错 | 说明 |
|---|---|
| 加目录 | 国赛明确不要目录，加了会被视为不符合规范 |
| 英文摘要 | 国赛摘要无需翻译成英文 |
| 摘要超页 | 摘要专用页含标题和关键词，整体不超一页 |
| 页码起点 | 从摘要页开始编"1"，不是从正文开始 |
| 附录不装订 | 附录必须与正文一起装订提交 |
| 支撑材料形式 | AI 使用详情属支撑材料，不是附录内容 |
