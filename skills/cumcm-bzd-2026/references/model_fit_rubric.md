# 模型适配性判定

> 判定框架源于 BZD 数模社 Skills 合集中的模型字典使用方式。
> 若有外部数模字典（5700+ 模型条目），应先查询字典再作判定，不要凭印象选型。

## 四分类结论

对每个候选模型，必须出具四选一结论：

| 结论 | 含义 | 后续动作 |
|---|---|---|
| **合适** | 与题目目标、数据结构、变量类型基本匹配 | 进入选型论证 |
| **有条件合适** | 方向正确，但需满足额外条件或补充处理 | 写明条件，判断能否满足 |
| **不合适** | 与任务目标、数据类型或核心假设明显冲突 | 记录淘汰理由 |
| **证据不足** | 现有信息不足以可靠判断 | 先补数据/补信息，再判 |

**"证据不足"是合法结论。** 数据还没看清时强行选型，比标注证据不足再去补数据要糟得多。

## 六个判定维度

每个候选逐项过一遍，缺项则判定不可靠：

### 1. 适用场景

- 模型原本解决什么类型的问题
- 本题是否属于该类型
- 有无已知的同类应用先例

### 2. 数据要求

| 检查项 | 说明 |
|---|---|
| 样本量 | 是否满足模型的最低样本要求 |
| 变量类型 | 连续 / 离散 / 分类 / 时序 / 空间 |
| 分布假设 | 是否需要正态、独立、平稳等前提 |
| 完整性 | 缺失与异常是否在模型可容忍范围 |
| 量纲 | 是否需要标准化，模型对量纲是否敏感 |

### 3. 关键假设

- 模型依赖哪些假设
- 本题数据是否满足
- 不满足时的后果与补救

### 4. 输入输出

- 模型的输入形式（向量？矩阵？序列？图？）
- 输出形式（数值？类别？分布？方案？）
- 与子问任务卡的"输入/输出"是否对得上

### 5. 禁忌点

模型在什么情况下会失效或产生误导。常见禁忌：

| 模型族 | 典型禁忌 |
|---|---|
| 线性回归 | 强非线性、共线性、异方差 |
| 时间序列 | 非平稳未检验、外推过远 |
| 聚类 | 簇形状非凸、量纲未统一、簇数预设不当 |
| 神经网络 | 样本量小、需可解释、无验证集 |
| 层次分析法 | 判断矩阵不一致、指标非独立 |
| 灰色预测 | 数据非单调、长期外推 |
| 熵权法 | 存在常数列（信息熵为 0） |

### 6. 检验方法

模型该用什么方式检验。若说不出检验方法，说明对模型的理解不足以使用。

## 针对性检验（硬性）

写完选型论证后执行：

> **把段落中的赛题背景删掉。如果这段话仍然能原封不动地用于其他题目，说明写的是模型教科书介绍，不是针对本题的选型。**

合格写法包含三要素：

```
问题X要求【问题目标】。根据题目条件和数据特征，该问题在数学上属于【问题类型】。
考虑到【模型适用理由】，选择【模型名称】进行求解，并针对【本题特点】
对模型的【目标函数、约束或参数】进行调整。
```

第三句（针对本题的调整）是区分"套模型"与"建模"的关键。

## 常见题型 ↔ 模型方向

仅用于**生成候选**，不代替适配性论证：

| 题型特征 | 可考虑方向 |
|---|---|
| 求最优方案、路径、排程、配比 | 线性/非线性规划、整数规划、启发式、元启发式 |
| 分类、判别、评级 | 逻辑回归、SVM、决策树、集成方法、判别分析 |
| 预测未来值 | 时间序列（ARIMA 族）、回归、灰色预测、机器学习回归 |
| 多方案排序选优 | 层次分析法、熵权法、TOPSIS、多目标决策 |
| 机理演化 | 微分方程、动力系统、仿真 |
| 统计推断、相关性 | 假设检验、回归、方差分析、相关分析 |
| 网络结构 | 图论、网络流、复杂网络指标 |
| 信号周期 | 傅里叶、小波、时频分析 |
| 达标时间、删失数据 | 生存分析（Kaplan-Meier、Cox） |
| 重复测量、组内相关 | 混合效应模型、GAMM |

### 字段与本文件六维的映射

字典字段与上面的判定维度几乎一一对应，且额外提供"模型缺陷"与"原理讲解"：

| 本文件的判定维度 | 字典字段 |
|---|---|
| 适用场景 | `适用场景` |
| 数据要求 | `数据要求`（含最少样本量、分布要求、预处理要求） |
| 关键假设 | `关键假设` |
| 输入输出 | `模型输入` / `模型输出` |
| 禁忌点 | `禁忌点`（以 ✗ 标注的具体误用） |
| 检验方法 | `检验方法` |
| — | `模型缺陷`（⚠️ 标注，含"可介绍条件"） |
| — | `原理讲解` |

字典的 `禁忌点` 与 `模型缺陷` 两个字段尤其有价值——它们把"教科书不会写但实践中会踩的坑"结构化了，这正是凭经验选型最容易缺的部分。

### 查询方式

```bash
# 首次使用：设置字典路径
export BZD_MODEL_DICT=<bzd 仓库>/skills/论文自查类/bzd-model-dictionary/assets/model-dictionary.json

# 按模型名查（选型自查）
python <wf>/scripts/query_model_dict.py --model 灰色预测 --brief

# 按大类/分组浏览（生成候选）
python <wf>/scripts/query_model_dict.py --category 优化模型 --limit 15

# 按适用场景检索（找替代模型）
python <wf>/scripts/query_model_dict.py --scene 小样本 贫信息 --limit 10

# 机器可读
python <wf>/scripts/query_model_dict.py --model ARIMA --json
```

脚本**不复制字典数据**，通过路径或环境变量只读引用，并在每次输出中携带原始许可声明。字典缺失时输出获取指引。

## AI 使用边界

AI 可用于：候选推荐、方案比较、适用条件分析、局限性讨论。

必须说明：

- 最终模型如何确定
- 哪些 AI 建议被舍弃
- **核心模型是否由参赛队自己推导**

照搬 AI 推荐的模型，是"模型名称与实际实现脱节"的主要来源。
