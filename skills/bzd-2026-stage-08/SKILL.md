# 阶段 8 · 全面审查 II：综合评审（BZD 双审精制流）

完整规则见主 Skill `cumcm-bzd-2026`（references/rubrics.md、feedback_l1_critic.md），本文件为阶段入口指令。

## 本阶段任务（切换陌生评委视角，自上而下整体打分；不共享阶段 7 中间结论）

1. **隔离声明**：本评审只依据"当届赛题 + 当前论文"，不使用历史对话中的解题思路、模型偏好或既有结论。
2. **先读题分解任务 → 制定并冻结本题专用百分制 rubric**（写入 `stages.8.rubric_frozen_at` 带时间戳）→ **然后才读论文**（防先入为主）。参考配比：摘要 10、格式 10、模型假设+建立+求解 70-75、其余质量 5-10；逐维配"满分行为描述"。
3. **90% 封顶**：每数值维度得分 ≤ 权重×0.9（满分理论上限 90/100）；封顶扣除标注"评委满分保留"，不算论文缺陷，释放的 10% 不加回。
4. **逐维评分**：每个给分/扣分点必须带位置证据（页码/公式号/图表号）；模型针对本题程度/单位/算法/数据来源/数值结果/可复现性/验证/灵敏度/可行性逐项过。
5. **评委式评价**：一段总评 + 最有分量优缺点（带位置）+ **创新盲区提示**（高度新颖的非常规路线可能被 AI 评审低估）。
6. **优先修改建议** 3-5 条按期望得分增益排序；不承诺奖项、不预测获奖概率。
7. **红队攻击**（若模式 championship）：反方评委攻击最弱章节 30 分钟，问题并入回修协议。
