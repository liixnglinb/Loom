# 阶段 7 · 全面审查 I：章节专项自查（BZD 双审精制流）

完整规则见主 Skill `cumcm-bzd-2026`（references/anti_patterns.md、template_library/* 各章自查清单），本文件为阶段入口指令。

## 本阶段任务（自下而上、按章节规则逐章体检；只定向修复，不重写全章）

按顺序逐章自查（每章用其模板文件内附的自查清单）：

1. **摘要**：15 项清单 + 独立阅读性三要素。
2. **问题重述**：题意保持（任务/条件/数字/单位/约束/附件/输出形式）+ 章节边界（分析/模型/算法/公式/结果不得漏进）+ 综述证据与虚构风险（文献四验）。
3. **问题分析**：任务覆盖映射 + 跨问联动真实性 + 数据依据 + 章节越界 + 框架图与正文一致性。
4. **模型假设**：来源/合理性/必要性/依据逐条；遗漏候选；强假设验证要求；假设-后文对应表。
5. **符号说明**：符号表↔正文双向核对（缺失/冗余/多义/大小写上下标漂移）+ 单位 + 首次定义 + 三线表版式。
6. **模型建立与求解**：任务-响应映射表（原题任务|模型|求解|结果|检验|状态）+ 数据预处理 + 选型针对性 + 参数/目标/约束 + 算法可复现 + 结果图表 + 检验匹配 + 灵敏度诊断 + 跨问联动与误差传播。
7. **模型评价**：优点有证据/不足带边界/改进对应/推广有对象；与摘要/结果/检验一致。
8. **参考文献与附录**：引用↔文末一一对应 + 格式统一（GB/T 7714）+ 数量 5-15 + **匿名性扫描**（正文/代码注释/路径/截图/文档属性/文件名）。
9. **AI 披露**：声明↔详情 PDF↔真实台账一致性；无"只写润色实际建模"式弱化。
10. **26 项 AI 合规清单**（2026 六维度：新规合规 4 / 幻觉与真实性 4 / 建模逻辑与题意 5 / 求解合理 3 / 官方写作规范 6 / 排版页数 4）逐项标注 `合格/存在问题/待核实` 附位置与修复建议，无空项；**死亡项**（AI 主导核心建模/虚构数据文献/声明与实际矛盾）→ P0。

## 回修协议

- P0/P1 → 立即定向修复（只改问题指向位置）→ 重跑受影响自查项 → 循环至 P0=P1=0（iteration cap 3）。
- P2/P3 → 评估后修复或记录接受理由。
- **没有问题的章节明确写"合理"，不为显得严格而虚构缺陷。**
