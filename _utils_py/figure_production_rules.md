# 论文级图表生产规范（figure_production_rules）

> 本工作区 `_utils/` 已注入与极速全自动流同款的图生产工具链。**数据图与流程图/架构图都必须按本规范生产**，不许图省事用随意样式/截图代管/空壳图。

## A. 数据图（结果 / 趋势 / 比较 / 分布）

1. **风格基线**：`import _utils.plot_utils`（或把 `_utils/` 加入 `sys.path`），用其 `setup_style()` 统一论文出版级风格（配色/字体/网格）。不要自造一套样式。
2. **图型选型与画法**：查 `cat _utils/chart_library.md`（70 类图型表：三阶段选型 → 具体图），命中对应配方 `cat _utils/figure_recipes_<类>.md`，或运行 `$PYTHON _utils/get_recipe.py <图型key>` 取可直接抄改的代码。
3. **真实数据**：图中数值必须来自真实计算结果（禁止手工编造/占位）；同一组结果只保留一种主表达（表承数值、图承趋势）。
4. **产出**：`figures/gen_fig_<key>.py`（可复现源码）+ `figures/fig_<key>.pdf`（SVG/PDF 矢量，中文用支持字体）。命名与 `SOLVING_RESULTS.md` 索引一致。
5. **质检（必跑）**：`$PYTHON _utils/figure_check.py figures/fig_<key>.pdf`——尺寸档位 + 视觉硬伤（坐标轴截断/标签重叠/空白异常）。退出码 1（FAIL）必修：读图改 `gen_fig_*.py` 重出，最多 3 轮。

## B. 流程图 / 架构图 / 技术路线图（HTML 矢量生产）

1. **手写 HTML+CSS（不画 PNG）**：flex/grid 自动布局（禁绝对坐标 → 免疫重叠/错位）；单文件自包含、无外链；画布透明只节点浅填充；**图内无标题**（标题交给论文 `\caption`）；公式写 `\(...\)` 由出图时 KaTeX 渲染。
2. **造型**：黑白基调 + 低饱和强调（彩色 ≤15%）；判定用圆角矩形（禁旋转菱形）；起止用胶囊；数据源圆柱、文档折角页；内在文字填本题真实方法/模型/判据（禁"数据预处理/建立模型"式空词）。
3. **语义连线**：实线=主流程；虚线=数据依赖/异步；虚线+强调色=回流/失败重试。是/否标签贴箭头旁，不悬空。
4. **3 候选择优（⛔ 每张流程/架构/路线图必走）**：
   - 同一种子下派生 3 个**结构不同**的候选（纵向主干 / 横向流水线 / 双栏对照 等；逻辑只有唯一贴合的范式时，3 版改为同骨架下不同分组/分区/焦点），禁为凑数硬造分支。
   - 3 版各转 PDF（见第 5 条）→ 过 `screenshot_capture.py --geom-check` 几何自检（溢出/越界/重叠）。
   - 按固定权重打分选 1：**逻辑忠实度 40%**（本题真实方法链/分支/回环画全、无空词）> 信息密度 20% > 对齐与美观 20%（等大等距、行列成线、箭头接中轴、无交叉）> 论文融合 20%（黑白基调、不瘦高撑页）。每维 0-5 加权求和。
   - 选中版复制为 `figures/fig_<name>.html` → 转最终 PDF；**落败候选删除，不得写入 figures/ 与论文**。
   - 三版得分与选择理由追加写 `_tmp/fig_choice_notes.md`（决策留痕，绝不进论文）。
5. **转 PDF（必用）**：`$PYTHON _utils/screenshot_capture.py --file figures/fig_<name>.html --out figures/fig_<name>.pdf --format pdf [--render-math]`（有公式必须加 `--render-math`）。产出单页、无白边、真矢量 PDF。
6. **兜底**：3 候选全部几何 FAIL → 取第一个能正常出 PDF 的候选转正；全部出不了 → 大幅精简重画一轮。

## C. 图索引（供写作阶段直接引用）

每张图产出通过质检后，在 `SOLVING_RESULTS.md` 图索引区**追加**一行：
`- fig_<name>.pdf — 建议 caption：<≤20字，如"问题一求解流程">`
写作阶段（stage05）直接按此索引 `\includegraphics`，不再二次造图。

## D. 红线

- ⛔ 图内不写标题；图表三有（前引/中引用/后解释）。
- ⛔ 禁 emoji、禁外链图片、禁整页大底色块、禁高饱和彩虹配色。
- ⛔ 打分留痕与落败候选绝不进正文/附录/任何 .tex。
